01 / Recording & patches

Evaluation uses the configured centered fraction. Training uses the seeded temporal/spatial sampler. The same recording and epoch reproduce the same crop; configured crop banks repeat across epochs. Restricts the ranking and blend normalization. Alternate representations of the same voxel have identical information scores.

02 / Information measure

Each patch's raw event volume is binned separately in x, y and time, pooling both polarities. More bins resolve finer structure; they can also make support sparse. Display resolution is unchanged. UI limit: 64 per axis. Neighbor events needed for full support. Lower values saturate sooner. Affects support only; all three scores are available in patch details.

03 / Ranking rule

How to read the demonstration

Scores describe these event statistics, not learned semantic importance. Empty patches score zero for all three measures. Negative autocorrelation can rank below empty patches.

The grid reads left to right, then down: highest score at the top left. Ties use the original token ID. The bar shows relative position within the displayed score range, not confidence.

Levels cover different physical volumes. Use one level/representation group for comparisons at a fixed scale. Cell coordinates are zero-based [x, y, t] within that level.

Images reuse the reconstruction inspector's RGB mapping and clip values to [0, 1]. Two-channel projections show positive events in red and negative events in blue. CSTR shows mean positive/negative time in red/blue, with count in green when present. The score always uses raw 3-D voxels, regardless of projection.
